# 正反例

全部取自真实期次。「改法」只示范写法，事实以当期正文为准。

## 封面区

**10/10 早刊（反例：副题另起新闻，导语复述）**

- 题：Deno 团队加入 Cloudflare，运行时再维护一年
- 副题：Deno Deploy 6 个月后关停；Oxide 完成 4.45 亿美元 D 轮，Axios 报估值 60 亿美元
- 导语：Deno 团队加入 Cloudflare（HN 约 1080 分）。Deno 运行时再维护一年，Deno Deploy 6 个月后关停。Oxide 官宣 4.45 亿美元 D 轮……

问题：
- 副题后半段讲的是 Oxide，和题无关。
- 导语前两句是题和副题的原话。
- 读完封面区只得到两件事，Deno 还重复了三遍。

改法：
- 题：Deno 团队加入 Cloudflare
- 副题：Deno 运行时再发一年修复版后停止开发，Deno Deploy 6 个月后关停
- 导语：Oxide 官宣 4.45 亿美元 D 轮，Eclipse 领投，Axios 报估值 60 亿美元。TypeSafe AI 融资 8.7 亿美元，估值 75 亿美元，a16z 领投。

**10/9 晚刊（反例：预告、时间窗、情绪词）**

> 这班是美国周五白天、上海周五晚上。PH 周五榜起来了：前几名几乎全是「给 agent 用的基础设施」——……访谈侧这一窗最吵的是……

改法：时间窗放进 `window`。导语第一句直接写「Zernio 约 158 分，Together Link 约 117 分，Busabase 约 106 分。」

## 判断：留下的

| 类型 | 判断 | 为什么能留 |
|---|---|---|
| A 行动 | 用 Deno Deploy 的项目要在 6 个月内迁走，Workers 和自托管二选一。 | 有对象、期限和选项。把产品名换掉，这句就不成立了 |

| C 连线 | Prime Agent 和 10/8 的 ts-rust 都是两周内由模型重写成 Rust，可对照验收：Prime 逐帧比界面和会话，ts-rust 作者称测过的真实项目全兼容。 | 共有的事实（两周、模型重写、Rust）具体到换掉任何一边都不成立，并给了对比点 |

**过不了替换测试的 C**：「Jev 和 10/7 的 OpenAI Decisions API 都只答判断题，拿你的页面验收任务各跑一批就能比出延迟和成本。」把 Jev 换成任何一个判断题模型（如 Strands Decider 2B），这句照样成立。

**勉强过关、应删的 B**：「想了解 AI 的人可以关注这类模型的后续进展。」不读这条新闻也会给这个建议，靠加一个反例的名字凑过替换测试，不算。
